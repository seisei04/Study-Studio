# Study Studio

Open index.html in a desktop browser. Keep course.js and studio.js beside it. The studio runs locally without installation, an account, analytics, or network requests. Some lessons direct you to separate development tools for coding practice.

To keep your GitHub copy private, create a **Private** repository and upload the files in this folder. Leave Pages disabled and collaborator access empty. Clone or download the repository to study locally. Publishing these static files to a web host would require separate access controls to restrict visitors.

Workbook answers and progress live in the current browser profile. Use the same profile and file location to resume. Clearing site data or using a private window can erase progress. GitHub stores the course files only.
